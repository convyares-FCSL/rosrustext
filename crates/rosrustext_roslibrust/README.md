# rosrustext_roslibrust

roslibrust/rosbridge adapter that projects `rosrustext_core` lifecycle semantics
into ROS-facing services and topics.

## Status

- Lifecycle parity complete
- Compatible with `ros2 lifecycle`, Python lifecycle managers, and Nav2

## Test

From the repo root (with ROS sourced):

```bash
./scripts/test/run_all_tests.sh
```
