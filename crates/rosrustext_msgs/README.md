# rosrustext_msgs

Bundled ROS 2 messages for [rosrustext](https://github.com/convyares-FCSL/rosrustext).

This crate contains generated Rust code for:
- `lifecycle_msgs`
- `bond`
- `std_msgs`
- `builtin_interfaces`

It is designed to allow `rosrustext` crates to be published to crates.io without requiring a local ROS 2 installation or `colcon` build environment for message generation.
